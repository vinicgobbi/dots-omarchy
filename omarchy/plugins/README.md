# Plugins do Omarchy shell

Lista dos plugins instalados via `omarchy plugin clone` (o código deles não é
versionado aqui, só o link de origem). A ordem/seção de cada um na bar está
em `../shell.json`.

|---|---|---|
| `bibek.media` | BibekBhusal0 | https://github.com/BibekBhusal0/omarchy-better-media |
| `dimitar.openvpn` | dstankovd | https://github.com/dstankovd/omarchy-openvpn |
| `mghizdavet.rss` | MariusGhizdavet | https://github.com/MariusGhizdavet/omarchy-rss |
| `omaconnect` | jitendradara12 | https://github.com/jitendradara12/omaconnect |
| `wian47.removable-drives` | Wian47 | https://github.com/Wian47/omarchy-removable-drives |

| `vinicgobbi.vpn` (meu) | vinicgobbi | https://github.com/vinicgobbi/omarchy-plugin-vpn |

Para reinstalar: `omarchy plugin clone <link-do-repo>`.
