# dots-omarchy

Minhas customizações do [Omarchy](https://omarchy.org/) (Hyprland e omarchy-shell). Só versiono o que alterei em cima do default.

- `hypr/` — `bindings.lua`, `input.lua`, `monitors.lua` (→ `~/.config/hypr/`)
- `omarchy/` — `shell.json` (layout da barra), `rss-reader.json` (tokens dos feeds ocultados) e `plugins/README.md` (lista de plugins com link de origem) (→ `~/.config/omarchy/`)

Aplicados pelo módulo `dots_omarchy` do post_omarchy, ou à mão copiando os arquivos para `~/.config`.
